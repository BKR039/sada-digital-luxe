| File | Purpose |
|---|---|
| `06_clients.md` | Real clients on file (currently none — see file for the fake-seed-data caveat). |
| `07_case_studies.md` | Public portfolio & Case Studies CMS durable memory, schema, and editorial workflow. |

| `09_future.md` | Intentionally postponed ideas — not scheduled, not started. |
| `10_todo.md` | Unfinished, actionable work with priority/dependencies/complexity/status. |
| `11_known_issues.md` | Known problems, never hidden, with priority and possible solutions. |
| `12_ai_notes.md` | Permanent rules for any AI/human working on this repo. |
| `13_project_health.md` | Realistic, evidence-based completion estimates per area. |

**Reference docs** (what things *are*, not what changed) live in `../docs/`: `SADA_BRAND_GUIDELINES.md`, `SADA_DESIGN_SYSTEM.md`, `SADA_CONTENT.md`, `SADA_ARCHITECTURE.md`, `SADA_PROJECT_CMS.md`, `DATABASE_RULES.md`, `SEO_CHECKLIST.md`, `PERFORMANCE.md`.

Update rule: after any completed feature, touch only the files it actually affects. Don't duplicate reference content here — this folder is for history, status, and standing rules, not a second copy of the design system or content docs.
